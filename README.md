#A multi-scale graph tide model with enhanced graph structure learning and spatiotemporal decoupling for load forecasting

**Correction**: After publication, we identified a data transcription error in Table 7 of the published article. The underlying experiments and original experimental outputs are unchanged. The corrected values do not affect the comparisons, findings, or conclusions reported in the article.
